# Rules for editing this site (read before every change)

Site for Heartlines International, a California nonprofit public benefit corporation (EIN 42-4681667). Plain HTML and CSS only (no frameworks or build step). Hosted on GitHub Pages at www.heartlinesinternational.com.

- Never delete or edit the `CNAME` file. It connects the custom domain.
- Never write "tax-deductible" until the founders say the IRS determination letter has arrived. Use "501(c)(3) application pending."
- Do not name the partner clinic. Use "a partner maternity clinic in the Philippines" until the founders confirm the clinic has agreed to be named.
- Never add bank details, signatures, a home address, or anyone's personal information.
- Health statements must stay within the clinic-approved wording already on the site. Don't add statistics unless the founders give a cited source.
- Donations are links to an outside donation page only. Never build a payment form on this site.
- Colors: cream #FAF2DC, navy #342D47, pink #F199A4, light pink #F6C3C9. Headings in Poppins, body text in Inter.
- Keep every page mobile-friendly, and keep the footer line identical on every page.
